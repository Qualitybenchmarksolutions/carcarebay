# CarCareBay Connected MVP — Production Backend Scaffold

This bundle contains:
- `carcarebay-app/` — Expo/React Native customer + partner prototype
- `CarCareBay-admin-dashboard/` — responsive admin dashboard
- `carcarebay-backend/` — PostgreSQL API with JWT roles, subscriptions, booking/job workflow, photo uploads, ratings and Razorpay order scaffolding

Important: this is **ready to connect to a real PostgreSQL/Supabase project but is not deployed**. You must supply the database URL, JWT secret and (if desired) Razorpay credentials.
